# Project Setup

## Installation

1. Install backend dependencies:

   ```sh
   pip install -r back/requirements.txt
   ```

2. Install frontend dependencies:
   ```sh
   cd front
   npm install
   ```

## Running the Application

1. Start the backend:

   ```sh
   cd back
   python api.py
   ```

2. Start the frontend:
   ```sh
   cd front
   npm run dev
   ```

✨ Your application should now be running! ✨
